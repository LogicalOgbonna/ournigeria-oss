# Nigerian State Budget Implementation Reports - Download Links Directory

> **Last Updated:** February 2026
> **Purpose:** Centralized directory of links where budget implementation reports (BIRs) / budget performance reports (BPRs) can be downloaded for all 36 Nigerian states + FCT.
>
> **Source Priority:** 1) Official State Website, 2) OpenStates.ng, 3) Budgetpedia.ng, 4) NGF/Other

---

## AGGREGATOR PORTALS (All States)

These portals host budget implementation reports for multiple/all states:

| Portal | URL | Coverage |
|--------|-----|----------|
| **Budgetpedia.ng** | https://budgetpedia.ng/ | All 36 states + Federal |
| **OpenStates.ng** | https://openstates.ng/ | All 36 states |
| **NGF Public Finance** | https://www.publicfinance.ngf.org.ng/ | All 36 states (fiscal data) |
| **BudgIT Foundation** | https://budgit.org/ | Reports & analysis for all states |
| **Budget Office of the Federation** | https://budgetoffice.gov.ng/index.php/resources/internal-resources/reports/quarterly-budget-implementation | Federal quarterly BIRs |

### Budgetpedia Pages by State Group:

## QUICK REFERENCE: FALLBACK SOURCES

If a state's official website is down or lacks reports, use these fallbacks in order:

1. **Budgetpedia.ng** - Most comprehensive; has quarterly BIRs for all 36 states with direct downloads
2. **OpenStates.ng** - BudgIT's open data portal; hosts budget documents for all 36 states
3. **NGF Public Finance Portal** - https://www.publicfinance.ngf.org.ng/ - Comparative fiscal data for all states
4. **BudgIT State of States Report** - https://budgit.org/post_publications/state-of-states-report-2025/ - Annual analysis

## NOTES

- **BIR** = Budget Implementation Report
- **BPR** = Budget Performance Report (used interchangeably with BIR by many states)
- Reports are typically published **quarterly** (Q1-Q4) with some states releasing them within 28-60 days after quarter end
- All direct PDF links were verified as of February 2026 but URLs may change over time
- For the most up-to-date reports, visit the state's official budget portal first, then fall back to aggregator sites
- Some states host reports on subdomain portals (e.g., `pfm.bo.gov.ng` for Borno, `mbp.en.gov.ng` for Enugu) rather than the main state website
