# CEO Plan: Content Engine — Claude Code Direct Pipeline

## Vision

### 10x Check
The 10x version transforms Claude Code from a chatbot into a **content production line**. Instead of manually generating one piece at a time through a broken RAG pipeline, Claude Code reads raw source documents directly from `packages/source/`, executes structured recipes, generates cross-domain content that combines budget + corruption + FAAC data, and outputs a week's content calendar across 4 platforms — all in a single batch run.

The current pipeline: run script → get wrong data from RAG → manually fix → post one thing.
The 10x pipeline: run batch command → Claude reads real documents → generates 14 content pieces → renders branded images → outputs a calendar. Review, approve, post.

### Platonic Ideal
A Nigerian data journalist on staff who has read every single budget document across 37 states and 8 years. Can instantly cross-reference a corruption case with the budget it looted from. Speaks fluent Pidgin. Never repeats content. Balances state/topic coverage. Produces publication-ready branded images and threads. Knows which platforms to target for which audiences.

## Architecture Overview

```
packages/content/
├── recipes/                    # Recipe definitions
│   ├── budget-expose.ts        # State budget breakdown
│   ├── corruption-impact.ts    # EFCC case + budget cross-reference
│   ├── state-comparison.ts     # Side-by-side state analysis
│   ├── faac-allocation.ts      # Federal allocation explainer
│   └── types.ts                # Recipe interface definition
├── formats/                    # Platform-specific formatters
│   ├── twitter-thread.ts       # 280-char tweet splitting
│   ├── instagram-carousel.ts   # Square image series
│   ├── video-script.ts         # Remotion integration
│   └── whatsapp-forward.ts     # Plain text + emoji
├── engine.ts                   # Recipe executor (reads source docs, generates content)
├── batch.ts                    # Batch generation + calendar
├── index.json                  # Content history index
├── generate.ts                 # Existing (API-based, preserved)
├── query.ts                    # Existing (DB-based, preserved)
├── render.ts                   # Existing (image renderer, reused)
├── templates/                  # Existing image templates
├── prompts/                    # Existing LLM prompts
├── questions/                  # Existing seed questions
└── output/                     # Generated content (gitignored)

Data flow:
  Recipe config
       ↓
  engine.ts reads packages/source/ files directly
       ↓
  Claude Code processes documents → generates content
       ↓
  Format adapters (thread/image/video/whatsapp)
       ↓
  render.ts for images / apps/videos/ for Remotion
       ↓
  output/ directory + index.json update
```
