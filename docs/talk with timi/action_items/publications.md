## Detailed Profiles

### 1. Premium Times (premiumtimesng.com) — Combined: 17

**Reach:** ~65M annual visits. Nonprofit arm CJID operates across West Africa.
**Why they'd collaborate:** Already built UDEME (budget tracker) and Dubawa.ai (AI fact-checker). They have the civic tech infrastructure but lack granular structured data (LGA-level FAAC, state budgets). OurNigeria fills their data gap.
**How they'd use OurNigeria:**
- Integrate FAAC allocation data into UDEME for project-to-allocation tracking
- Feed structured fiscal data into Dubawa.ai for fact-checking government claims
- Power data journalism investigations with queryable budget data
- Joint grant applications (MacArthur, Luminate already fund both civic data and CJID)
**Contact path:** Direct outreach to CJID team. Shared mission alignment.
